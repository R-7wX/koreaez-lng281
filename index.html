กดปุ่ม 🔊 เพื่อฟังเสียงเกาหลีทุกประโยค และทำแบบฝึกหัดสั้นๆ ท้ายแต่ละหัวข้อเพื่อเช็กความเข้าใจทันที

ตารางสรุปตัวชี้ 4 ชุดที่ต้องแม่น 100%

ไวยากรณ์ ความหมาย / หน้าที่ มีตัวสะกด (받침 O) ไม่มีตัวสะกด (받침 X) ตัวอย่าง (คลิกฟังเสียง)
이에요 / 예요 เป็น, คือ (วางหลังคำนาม) + 이에요 + 예요
이 / 가 ตัวชี้ประธาน 1 (เน้นตัวประธาน / ใช้กับ 있어요, 없어요, 뭐예요) + 이 + 가
은 / 는 ตัวชี้ประธาน 2 / หัวเรื่อง (แนะนำตัว, เปรียบเทียบ) + 은 + 는
을 / 를 ตัวชี้กรรม (ใช้กับ 좋아해요 / 싫어해요) + 을 + 를
💡 เกร็ดสำคัญของคำว่า "ฉัน" (저): • ใช้กับ 은/는 → 저는 (ฉัน...) • ใช้กับ 이/가 → 제가 (ฉันเป็นคน...) • แสดงความเป็นเจ้าของ "ของฉัน" → 제 เช่น 제 이름 (ชื่อของฉัน), 제 생일 (วันเกิดของฉัน), 제 거예요 (เป็นของฉัน)

⚡ ฝึกเร็ว: เลือกตัวชี้ให้ถูก (Batchim Drill)

❤️ ชอบ / ไม่ชอบ (Lecture 14)

N + 을/를 좋아해요. = ชอบ ...
N + 을/를 싫어해요. = ไม่ชอบ ...
  • 아메리카노를 좋아해요? — ชอบอเมริกาโน่ไหม?
  • 네, 아메리카노를 좋아해요. — ใช่ ชอบอเมริกาโน่
  • 라면을 싫어해요. — ไม่ชอบรามยอน
  • 저는 운동을 좋아해요. — ฉันชอบออกกำลังกาย
  • 크루아상을 싫어해요. — ไม่ชอบครัวซองต์

คำศัพท์คาเฟ่จาก Lecture 14: 아메리카노(를), 라테(를), 밀크티(를), 레모네이드(를), 와플(을), 샌드위치(를), 크루아상(을), 운동(을), 춤(을), 초콜릿(을)

🍽️ การสั่งอาหาร / ขอของ & ถามสิ่งของ (Lecture 7–8)

N + 주세요. = ขอ ... หน่อยครับ/ค่ะ
N1 + 하고 + N2 = N1 และ N2
이게 뭐예요? / 저게 뭐예요? = นี่/นั่นคืออะไร?
  • 어서 오세요. 뭘 드릴까요? — ยินดีต้อนรับ รับอะไรดีคะ?
  • 냉면 두 그릇 주세요. — ขอบะหมี่เย็น 2 ชาม
  • 빵 세 개하고 콜라 다섯 병 주세요. — ขอขนมปัง 3 ชิ้น และโคล่า 5 ขวด
  • 여기요, 물 좀 주세요. — ขอโทษครับ ขอน้ำหน่อยครับ
  • 우산 누구 거예요? → 제 거예요. — ร่มของใคร? ของฉันค่ะ
  • 고마워요. → 아니에요. — ขอบคุณนะ → ไม่เป็นไร

A + 이/가 + [สถานที่] + 에 있어요 / 없어요. = A อยู่ / ไม่อยู่ที่ ...
A + 이/가 + [สิ่งของ] + [ตำแหน่ง] + 에 있어요. = A อยู่ [บน/ใต้/หน้า/หลัง...] ของ ...
A 하고 B 사이에 있어요. = อยู่ระหว่าง A กับ B
