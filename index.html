❤️ ชอบ / ไม่ชอบ (Lecture 14)

N + 을/를 좋아해요. = ชอบ ...
N + 을/를 싫어해요. = ไม่ชอบ ...
  • 아메리카노를 좋아해요? — ชอบอเมริกาโน่ไหม?
  • 네, 아메리카노를 좋아해요. — ใช่ ชอบอเมริกาโน่
  • 라면을 싫어해요. — ไม่ชอบรามยอน
  • 저는 운동을 좋아해요. — ฉันชอบออกกำลังกาย
  • 크루아상을 싫어해요. — ไม่ชอบครัวซองต์
